#### 0. 한 줄 요약

**표본 전시실** — 러닝화를 판매 상품이 아니라 관찰 · 계측하는 표본으로 다룬다. 흰 프레임의 유리 상자 같은 카드, 격자선, 수치는 고정폭 글꼴. **강조색은 딥 틸 `#1D7A72`, 보조 강조색은 코랄**이다.

#### 1. 최종 설계

#### 1-1. 컨셉

- 데미언 허스트의 포름알데히드 표본 연작에서 시각 언어를 빌렸다 — 두꺼운 흰 프레임, 유리 상자, 표본번호.
- 카드 캡션은 표본번호 형식(`NO.01 · 조깅·회복주`, IBM Plex Mono).
- 신발 이미지는 같은 각도 · 같은 방향 · 같은 배율로 맞춘다(`01b_catalog_images.md` — 대표 이미지 고르기).
- 구매 버튼 · 할인 배지 · 가격 강조 같은 커머스 요소를 두지 않는다. 정보 페이지다.

#### 1-2. 색 — `src/index.css`

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--accent` | `#1d7a72` 딥 틸 | 고른 필터 칩 · 찜 하트 · 평점 숫자 · 고른 정렬 · 토글 · 주요 버튼 |
| `--coral` · `--coral-strong` · `--coral-soft` · `--coral-border` | `#ff7a59` · `#c2462a` · 옅은 배경 · 테두리 | **보조 강조** — AI 리뷰 요약 상자, 관리 화면 "보완 필요" 탭. 글자 · 선은 `--coral-strong` |
| `--bg-dark` · `--bg-panel` | `oklch(0.11 0 0)` · `oklch(0.13 0 0)` | 히어로 |
| `--bg-light` | `oklch(0.965 0.002 90)` | 본문 바탕(갤러리 톤 오프화이트) |
| `--text-strong` · `--text-mid` · `--text-weak` · `--text-invert` | `oklch(0.16 / 0.42 / 0.58 / 0.97 0 0)` | 글자 위계 |
| `--border` · `--border-light` | `oklch(0.8 0 0)` · `oklch(0.85 0 0)` | 격자선 · 프레임 안쪽 선 |
| `--danger` · `--danger-soft` | `oklch(0.5 0.18 25)` · `oklch(0.7 0.12 25)` | 오류 문구 · 지우기 |

- **강조색은 딥 틸, 보조 강조색은 코랄.** 딥 틸은 "고른 것 · 내 것 · 점수"에, 코랄은 그와 구분해야 하는 것(AI 요약 · 할 일)에만 쓴다. 그 밖의 유채색은 쓰지 않는다.
- 무채색은 oklch 로 명도만 바꾼다.

#### 1-3. 글꼴

- 본문 `--font-base` Noto Sans KR(400~800), 수치 · 캡션 `--font-mono` IBM Plex Mono. 로고 "RUNSHOES" 는 Archivo Black.
- 크기 위계: 히어로 카피 > 모달 모델명 > 카드 모델명 > 평점 > 라벨 · 버튼 > 스펙 수치 · 캡션.

#### 1-4. 크기 토큰과 배율 — `src/tokens.css`

- 글자 크기는 **기준값 × `--text-scale`** 로 쓴다: `font-size: calc(var(--fs-card-model) * var(--text-scale))`.
- 배율은 영역에 직접 선언한다 — 필터 칩 · 마이페이지 목차 · 활동 요약 1.3, 정렬 · 카드 · 랭킹 · 추천 결과 · 관리 폼 칸 묶음 제목 1.5, 카드 모델명 1.3(`--model-scale`), 카드 찜 알약 1.2(`--like-scale`). 헤더 · 히어로 · 페이지 제목은 배율을 받지 않는다.
  - `:root` 토큰에 `var()` 를 섞으면 `:root` 에서 값이 굳어 하위에서 바꿀 수 없다 — 그래서 배율은 영역 선택자에 둔다.
- 떠 있는 버튼 — 오른쪽 아래 "맨 위로", 왼쪽 아래 챗봇, 같은 크기 · 같은 거리(`--fab-size` 48px · `--fab-offset` 16px). 좌우 여백 `--page-gutter`(72 · 64 · 20px)가 버튼 범위보다 넓어 데스크톱 · 태블릿에서는 스크롤해도 버튼이 글자 위를 지나가지 않는다.

#### 1-5. 형태

- **카드** — 이미지 영역 `aspect-ratio: 4/3`, 흰 10px 프레임 + 안쪽 1px 선, 아래 얇은 기준선. 카드 사이는 갭 없이 1px 격자선으로 나눈다. 모서리는 각지게(0).
- **그림자** — 카드에는 없다. 모달 · 드롭다운 같은 실제로 떠 있는 것만.
- **칩 · 토글** — 완전 둥근 모서리(`border-radius: 100px`).
- **여백 리듬** — 섹션 사이는 크게(24~40px), 카드 안은 촘촘하게(6~18px).
- **히어로** — 어두운 바탕에 용어 해부도 사진 3장(드롭 · 아웃솔 · 스택하이트)이 4초마다 넘어가는 슬라이드. 라이브러리 없이 `setInterval` + 정리.
- **드롭다운** — `appearance: none` + 배경 화살표(오른쪽 12px, 안쪽 여백 36px), 모든 `<select>` 공통.
- **화살표** — 글자 ‹ › 대신 SVG `Chevron`(글꼴 기준선 때문에 가운데가 맞지 않았다).

#### 1-6. 반응형

| 폭 | 그리드 | 그 밖 |
|---|---|---|
| 1200px 이상 | 3열 | 검색창이 칩 오른쪽 |
| 768~1199px | 2열 | 검색창이 칩 위 한 줄, 칩은 가로 스크롤(오른쪽이 흐려진다) |
| 767px 이하 | 1열 | 햄버거 서랍, 모달은 세로로 쌓고 스크롤 |

#### 1-7. 하지 않는 것

- 장식용 그라데이션(히어로 이미지 위 가독성용 어두운 오버레이 · 옅은 상자 바탕은 허용) · 카드 드롭섀도 · 이모지 · 딥 틸 · 코랄 밖의 유채색 · 모든 요소를 같은 회색 카드에 담기 · 균일한 여백 · 커머스 요소 · 각도 · 방향 · 배율이 서로 다른 신발 이미지.

#### 2. 왜 이렇게 했나

- **표본으로 보이게.** 러닝화 사이트는 대부분 쇼핑몰이다. 이 아카이브는 스펙과 리뷰만 다루므로, 상품이 아니라 계측 대상처럼 보여야 내용과 맞는다 — 프레임 · 격자 · 고정폭 수치 · 표본번호가 그 장치다.
- **유채색을 적게.** 유채색이 적으면 그 색이 곧 "봐야 할 곳"이다. 딥 틸은 고른 필터 · 내 찜 · 평점에, 코랄은 그와 성격이 다른 것에만.
- **크기를 토큰 × 배율로.** 홈 카드 글씨를 키울 때 값 수십 개를 고치지 않고 배율 하나로 바꾸려고. 마이페이지 · 관리 폼 제목도 홈 정렬과 같은 크기를 쓰게 같은 배율을 받는다.

#### 3. 시도했던 것들

- **AI 디자인 시안에서 시작했다(2026-07).** 프롬프트(`archive/design-prompt.md`)로 hi-fi HTML 시안을 받고, 인계 문서(`archive/design-handoff.md`)대로 React 로 옮겼다. 1차 수정(2026-07-21)에서 히어로 3분할이 신발 세 켤레로 보이던 것 · 스펙 라벨이 부위와 맞지 않던 것 · 카드가 흰 박스에 가깝던 것을 고쳤다.
- **히어로 해부도 3분할 → 사진 슬라이드.** 시안은 신발 한 짝이 패널 셋에 걸쳐 이어지고 라벨이 부위에 선으로 붙는 정지 화면이었다. 지금은 용어별 사진 3장이 넘어가는 슬라이드다.
- **보조 강조색 코랄을 더했다(2026-11-01 사용자).** 처음 원칙은 "강조색은 딥 틸 하나"였다. 그런데 AI 리뷰 요약 상자가 베스트 리뷰(옅은 틸)와 구분되지 않았고(그 전에는 앰버였다), 관리 화면의 "보완 필요" 탭은 할 일이라 다른 탭과 구분돼야 했다. 둘을 구분하는 보조 강조색으로 코랄을 정했다.
- **코랄을 바탕용과 글자용으로 나눴다(2026-11-01).** 원색 `#FF7A59` 는 흰 바탕 대비 2.57:1 이라 글자 · 선으로 쓰면 읽기 어렵다. 옅은 바탕 · 테두리는 원색에서(`--coral-soft` · `--coral-border`), 글자 · 선 · 고른 탭은 진한 코랄 `#C2462A`(`--coral-strong`, 흰 바탕 5.0:1)로 나눴다.
- **화면 다듬기(2026-10-30 사용자).** 마이페이지 · 관리 폼의 제목 크기를 홈 정렬과 같은 토큰으로, 체험 카드 · 갤러리 화살표를 SVG 로, 찜 카드를 행택 모양(끈 구멍 · 바코드)으로. 자세한 것은 `02_screens.md` 3절.
