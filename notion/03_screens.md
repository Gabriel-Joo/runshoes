# 03 화면

RUNSHOES의 화면은 React로 만든 단일 페이지 앱(주소가 바뀌어도 페이지를 새로 받지 않고 화면만 갈아 끼우는 웹 앱)이다. 화면은 모두 11개로, 주소가 다른 화면 10개와 신발 상세 창 하나다. [docs:02_screens.md:6] [docs:02_screens.md:10] 이 편은 화면 전체의 지도이고, 자세한 것은 아래 두 편과 기능마다의 편에 있다.

## 중심은 홈 하나

화면의 중심은 홈이다. 홈에서 용도로 거르고 이름으로 찾고 줄을 세운 뒤, 카드를 누르면 상세 창이 열려 스펙과 리뷰를 본다. 찾고, 누르고, 보는 흐름이 한 화면 안에서 끝난다. [docs:02_screens.md:10] 홈 옆에는 따로 연 화면이 셋 있다. 다섯 가지를 묻고 맞는 신발을 골라 주는 추천받기(→ 「추천받기」), 고른 신발을 점수 없이 나란히 놓는 비교하기(→ 「비교하기」), 평점과 리뷰로 매긴 순위인 러너들의 선택이다. [docs:02_screens.md:19-21] 러너들의 선택의 평점과 리뷰는 가상 사용자 200명이 쓴 시드 리뷰 1,800건(2026-11-17 운영 공개 API)에서 나온다. [docs:01e_seed_reviews.md:6] [docs:01e_seed_reviews.md:10]

로그인한 사람에게는 자기 리뷰와 찜을 모아 보는 마이페이지가 있고, 관리자에게는 신발을 등록하고 고치는 관리 화면이 있다(→ 「관리 화면」). [docs:02_screens.md:23-24] 로그인과 가입 화면은 성공하면 보던 화면으로 돌려보낸다(→ 「로그인과 체험 계정」). [docs:02_screens.md:22] 화면 왼쪽 아래에는 챗봇 단추가 늘 떠 있다(→ 「챗봇」). [docs:02_screens.md:87]

화면을 지키는 경로 가드는 화면 안내용이다. 로그인하지 않은 사람을 로그인 화면으로 보내 줄 뿐이고, 실제 권한은 서버가 막는다. [docs:02_screens.md:27] 화면 크기는 세 구간으로 나눈다. 넓은 화면에서는 카드가 한 줄에 셋, 태블릿 폭에서는 둘, 휴대폰에서는 하나씩 서고, 목록에서 상세 창으로 가는 흐름은 어느 크기에서나 같다. [docs:02_screens.md:88]

## 갈림길: 목록과 상세를 한 화면에

과제 요건이 단일 화면 구조를 지키는 것이었다. 그래서 상세를 홈 위에 뜨는 창으로 두고, 어느 신발을 열었는지를 주소에 남겼다. 그러면 링크를 받아 열거나, 새로 고치거나, 로그인하러 갔다 와도 같은 신발 창으로 돌아온다. [docs:02_screens.md:93] 이렇게 한 화면에 둔 홈과 상세 창의 자세한 모습은 → 「둘러보기와 상세」에 있다.

## 보이는 모양

화면은 러닝화를 판매 상품이 아니라 관찰하고 재는 표본처럼 보이게 꾸몄다. 흰 사진 칸을 둔 카드와 격자선, 강조색 딥 틸 하나와 보조 강조색 코랄만 쓴다. [docs:02b_design_system.md:10] 구매 버튼이나 할인 배지 같은 쇼핑몰 요소는 두지 않는다. [docs:02b_design_system.md:19] 색과 글꼴과 크기의 규칙은 → 「디자인」에 있다.
